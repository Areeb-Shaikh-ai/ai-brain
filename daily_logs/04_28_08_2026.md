## [Phase 2] Neural Perception (Tokenization)
- **Tokenization logic:** Implemented `AutoTokenizer` to analyze sub-word splitting.
- **Insight:** Rare strings (e.g., specific names) incur a higher "Token Tax," consuming the 32k context window faster than common dictionary terms.

## [Phase 3] Semantic Understanding (Embeddings)
- **Vector Mapping:** Integrated `sentence-transformers` (`all-MiniLM-L6-v2`) to map text into 384-dimensional mathematical space.
- **Metric:** Utilized Cosine Similarity to measure semantic distance.
- **Result:** Verified that the model understands "Contextual Holism" (e.g., identifying that "Laptop" and "Computer" are mathematically closer than "Laptop" and "Fruit").

## 🏗️ Technical Milestone: Long-Term Memory (RAG)
Successfully implemented the Retrieval-Augmented Generation (RAG) pipeline. This allows the AI to query external local files to answer specific questions, bypassing its knowledge cutoff and reducing hallucinations.

### 1. Implementation Architecture
*   **Knowledge Ingestion:** Developed a system to read and "chunk" textual data from the `knowledge/` folder.
